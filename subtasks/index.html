What it does

Jira makes you create subtasks one at a time. Bulk Subtasks adds an Add subtasks panel to the issue's Details sidebar. Paste however many lines you have, press the button, and each line becomes a subtask of that issue.

Using it

  1. Open any Jira issue that can have subtasks.
  2. Find Add subtasks in the Details panel on the right.
  3. Paste or type one subtask per line.
  4. Press Create subtasks.

The panel reports what it did, for example Created 3 subtasks. 1 duplicate line skipped.

What it cleans up for you

Lists get pasted out of meeting notes, Confluence pages, spreadsheets and chat, so they arrive with formatting attached. The app strips it before creating anything:

  • bullet characters — -, *, •, –, —
  • numbering — 1., 2), 3 -
  • checkboxes — [ ], [x], at either end of the line
  • blank lines, stray whitespace and Windows line endings
  • duplicate lines, compared without regard to case

Limits

  • 50 subtasks per run. Paste the rest and run it again.
  • Summaries longer than 240 characters are trimmed.
  • The issue must be of a type that allows subtasks. Subtasks themselves cannot have subtasks.

Who creates the subtasks

You do. The app acts as the signed-in user, so the subtasks carry your name and respect your project permissions. If a project refuses unassigned issues, the subtasks are assigned to you.

What it costs

Nothing. There is no paid tier, no trial and no user limit. It is built on Atlassian Forge, runs entirely inside Atlassian's cloud, and stores no data at all.
