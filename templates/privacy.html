Simple Issue Templates

Simple Issue Templates ("the app") is a Forge app that runs entirely inside Atlassian's cloud infrastructure. This policy describes what the app stores and who can reach it.

What the app stores

When a user saves an issue as a template, the app stores a copy of:

  • the issue summary and description
  • issue type, priority, and labels
  • the project key the template was created from
  • the summary, description, and issue type of each subtask
  • the Atlassian account ID of the assignee on the issue and on each subtask

Account IDs are pseudonymous identifiers issued by Atlassian. The app stores no names, email addresses, or profile details.

Where it is stored

All of the above is written to Atlassian Forge storage, which is hosted by Atlassian and scoped to the customer's own Atlassian site. The data:

  • is never transmitted to the app developer
  • is never transmitted to any third party
  • never leaves Atlassian's infrastructure

The app makes no network requests to any host outside Atlassian. It qualifies for Atlassian's Runs on Atlassian programme, which is granted only to apps that store all data inside Atlassian's own cloud and perform no external data egress.

What the app does not do

The app does not collect analytics, does not use cookies or tracking pixels, does not profile users, does not use any data for advertising, and does not train any model on customer data.

Who can see the data

Only users on the customer's own Atlassian site, subject to that site's existing Jira permissions. The app acts on behalf of the signed-in user, so it can never read or create an issue that the user could not read or create themselves.

Retention and deletion

Templates persist until a user deletes them in the app, or a site administrator uninstalls the app. On uninstall, the app's stored data is removed in line with Atlassian's data retention behaviour for Forge app storage.

To request deletion sooner, delete the templates in the app or uninstall it.

Data controller and contact

The customer's organisation is the data controller for issue content. Questions about this policy: support@harvizzle.com.
