How to get help with any harvizzle app.

Email support@harvizzle.com
Target first response: two business days, Monday to Friday. Email is monitored daily, including weekends, and anything affecting app availability is prioritised.

This is the support page for every harvizzle app, not only the one whose documentation you arrived from. The address above is the same for all of them.

What to include

These three things let a problem be reproduced straight away, and usually remove a round trip:

  • your site URL, for example yourcompany.atlassian.net
  • the issue key or page involved, for example ABC-123
  • what you expected to happen, and what happened instead

Screenshots help. Please do not send credentials or API tokens — they are never needed.

Reporting a bug

Email the address above. There is no portal to register for and no ticket number to chase. You will get a reply from a person.

Requesting a feature

Same address. Each app's documentation lists what it deliberately does not do yet; if the thing you need is on that list, saying so moves it up.

Security

To report a suspected security issue, email support@harvizzle.com with "security" in the subject line. Every harvizzle app runs entirely on Atlassian Forge and makes no network calls outside Atlassian, so no customer data is held on any harvizzle server.

Service status

The apps run on Atlassian Forge inside Atlassian's own cloud. If Jira or Confluence is up, the apps are up. Platform-wide incidents are reported at status.atlassian.com.
