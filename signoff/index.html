What it does

Confluence has no way to say "this page has been signed off". Teams end up doing it in comments, where it is invisible to anyone who has not read the whole thread. Page Sign-off adds an Approval item to the page byline — the line under the title with the author and the reactions. Anyone who can view the page can open it, request sign-off, or record a decision.

Using it

  1. Open any Confluence page and click Approval in the byline.
  2. Choose how many approvals the page needs, from one to five.
  3. Click Request approval. The status becomes Pending.
  4. Approvers open the same item and choose Approve or Request changes, with an optional note.

How the status is decided

  • Not requested — nobody has asked for sign-off yet.
  • Pending — requested, and still short of the number of approvals required.
  • Approved — enough people have approved.
  • Changes requested — at least one person asked for changes. One objection blocks the page regardless of how many approvals it already has.

Each person gets one decision. Changing your mind replaces your earlier decision rather than adding a second one. Start over clears every decision and returns the page to Not requested.

Approvals do not survive edits silently

The app records which version of the page was approved. If the page is edited afterwards, the decision list says so, so a sign-off from three revisions ago is never mistaken for a sign-off on what is on screen now. Ask again with Start over.

What it costs

Nothing. There is no paid tier, no trial and no user limit.

That is deliberate. The established app in this niche was free, converted to paid, and its cloud rating has sat near the bottom of the category ever since. Page Sign-off is not going to do that.
